# Healthcare-Report
My Healthcare Dashboard provides a clear and insightful overview of hospital data 🏥📊, bringing together key healthcare indicators and patient insights on a single page to keep the analysis focused and impactful:

**Global Overview (First Page)**

• **Key KPIs:** Total Admissions, Average Length of Stay, Number of Patients, and Total Costs.

• **Patient Segmentation:** Analysis of patient distribution by blood type, gender, and age category.

• **Medical Conditions:** Overview of the most common health conditions, including Diabetes, Hypertension, Obesity, Arthritis, Cancer, and Asthma.

• **Patient Trends:** Evolution of the number of patients over time, highlighting monthly variations.

• **Medical Test Results:** Distribution of test outcomes across three categories: Abnormal, Inconclusive, and Normal.

• **Dynamic Filters:** Interactive filtering by year, quarter, hospital, medical condition, and medication.

This project allowed me to showcase my skills in data modeling, data analysis, and visualization using Power BI.

Working with a healthcare dataset, I designed an interactive and well-structured dashboard to transform raw hospital data into meaningful insights, facilitate data exploration, and support data-driven decision-making.
